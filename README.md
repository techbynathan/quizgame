# 🎯 Quiz Game

An interactive web-based quiz game built with vanilla HTML, CSS, and JavaScript.

## Features

- **Default Questions**: Pre-loaded quiz questions to get started immediately
- **Custom Questions**: Create your own quiz questions with custom choices and answers
- **Difficulty Levels**: Choose from three difficulty settings:
  - **Medium**: 15 attempts
  - **Hard**: 10 attempts
  - **Insane**: 2 attempts
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Real-time Feedback**: Immediate feedback on answer correctness
- **Score Tracking**: Keep track of your score throughout the quiz

## How to Play

1. **Select Question Source**: Choose between default questions or create custom questions
2. **Pick Difficulty**: Select your preferred difficulty level
3. **Answer Questions**: Click on choices or type A, B, C, or D
4. **Get Feedback**: Receive instant feedback on your answers
5. **View Results**: See your final score and percentage at the end

## Custom Questions

You can create your own quiz questions by:
1. Selecting "Custom Questions" from the Question Source dropdown
2. Entering your question and four choices
3. Selecting the correct answer
4. Clicking "Add Question" to add more questions
5. Clicking "Start Quiz with Custom Questions" to begin

## Files

- `index.html` - Main HTML structure
- `ui.js` - Game logic and UI interactions
- `styles.css` - Styling and responsive design
- `quizgame.js` - Node.js version (CLI-based quiz)

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- JavaScript (Vanilla)

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Start playing!
